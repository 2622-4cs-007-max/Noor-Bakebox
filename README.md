# Noor's Bake Box

A responsive bakery website built using **React** and **Vite**. It showcases delicious bakery products, customer reviews, and order information through reusable React components.

## Features

- Responsive bakery website
- Home section with an automatic image slider
- Reusable React components
- Product cards with bakery images
- Customer reviews and star ratings
- Order information and price calculation
- Contact information and stall details
- Smooth scrolling and hover animations

## Technologies Used

- React
- JavaScript
- CSS
- Vite
- Google Material Symbols

## How to Run the Project

1. Clone or download the project.
2. Open the project folder in the terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.
